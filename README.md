# Connect4

This project implements a Python based connect4 game featuring 4 distinct AI agents including a random, rule-based,
minimax and ml agents. The primary goal is to explore different AI levels/strategies, implement them and evaluate
their performance against each other. To do this a series of simulation was conducted, where two agents where played 500
and the results were logged for analysis.

### Steps for execution

- clone the repository
- create and activate a virtual enviroment

Linux
```python
python3 -m venv .venv
source .venv/bin/activate
```
Windows
```python
py -m venv .venv
.\.venv\Scrips\Activate.ps1
```
- Install the dependencies
```python
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```
- run the game
```python
python3 main.py
```
- choose which stream you want (Human vs AI or AI vs AI) and select your agents
- to run tests:
```python
python -m unittest discover -p "test_*.py"
```

## Random vs Rule based (26-473 with 1 draw)

The performance evaluation between the random and rule-based agent shows the rule based agent commands a 94% winning
rate. This stark difference in performance can be attributed to the difference in their decision-making logic. Whilst
the random agent had no premonition to win or stop its opponent from winning, the rule based agent operated on a defined
set of rule that ensured:

- checking for an immediate move and taking it
- checking that the opponent is about to make a winning move and blocking it
- resorting to a random move if neither of the above applies

This simple but effective logic allows the rule-based agent to capitalize on immediate opportunities and defend itself
against obvious losses. Of course this is not fool-proof as the random agent can occasionally stumble into wins, but I
can say this is because for the first 2 to 3 moves the rule-based agent is also playing randomly due to there not being
enough moves to determine a win for either agent.

## Rule based vs Minimax (0-497 with 3 draws)

The result of the simulation between the rule based and minimax agent puts the minimax agent at a 99% win rate,
demonstrating a clear hierarchy in effectiveness and the strategy of depth search. The major factor in this outcome is
that the minimax agent uses a depth search algorithm (looking ahead x amount of steps, in this case 4) incorporating
alpha beta pruning and heuristic evaluation to score the board. This allows it to explore future game states, anticipate
responses from the opponent and choose moves that maximise winning chances by intuitively scoring moves and severely
punishing bad moves. This intense search averaged at 697 nodes evaluated per game and a grand total of 40,856 prunes
for efficiency. The minimax agent can also set multi turn traps that the rule-based agent doesn't have the foresight for
withs its one move ahead win/block methodology.

## ML vs Minimax (500-0)

The ML agent reveals a dominant performance, achieving a 100% win rate across 500 simulated games. the agent operates
using a policy network trained specifically on data generated by simulating games played by a minimax agent, effectively
mimicking the minimax agent. this of course has its fault as now the ml agent only wins when it starts the game.
Although I find that the low node count for the minimax agent is concerning especially when compared to that of the
minimax vs rule based agent and needs more investigating, however I attribute it to be due to the fact that the ml agent
when playing first, rapidly established positions from which the minimax agent, at depth 4 could forsee no path to avoid
a loss, leading to very short but effective search paths.
